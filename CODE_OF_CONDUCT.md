# Code of Conduct

Participation in this repository should be respectful, inclusive, and focused on
improving the Jenkins and Amazon EKS delivery example. Treat contributors with
professionalism, assume good faith, and keep reviews focused on the work.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, doxxing, deliberate disruption, or sharing credentials and private data.

If a concern cannot be handled in the relevant issue or pull request, contact the
repository owner at [tnt850910@aol.com](mailto:tnt850910@aol.com). Include only
the context needed to investigate and redact secrets and personal data.

This code sets participation expectations only.
